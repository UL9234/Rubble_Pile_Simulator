# 程序化废墟碎片生成（煎饼式坍塌场景）

本文档描述 `Assets/MITLL/Scripts/Debris/ProceduralSlabFactory.cs` 与 `DebrisSpawner.cs` 中
`-procdebris 1` 这条生成路径的算法、参数与已知限制。

## 1. 为什么不用现成资产

模拟器自带的 `debris.fbx` 是"一个文件 + 17 个子网格 + 一张调色板贴图"的散块库；公开的免费废墟包
（Destroyed City / Destroyed Walls / Construction Site Kit 等）能覆盖一部分形态，但风格、比例与
"可生成的单块碎片"这一用途都不够贴合。因此改为**按层程序化切分楼板**：尺寸、层数、厚度、裂缝形态
全部由参数控制，碎片天然就是"一块楼板裂开后的样子"。

## 2. 算法

每一层在水平面上生成一次完整"楼板 → 碎片"的切分，层与层之间在竖直方向按固定间距排列。

0. **整体布局：所有层同时出现**
   所有层的所有碎片**在同一帧生成**：第 k 层的**底面**严格位于 `spawnposy + k × 3 m`，每层都是一块水平平板，
   碎片朝向为**单位朝向（无任何随机旋转）**，yaw 就是切割出来的方向。生成后等待 `-pancakelayergap` 秒让其坍塌落定，
   再冻结（销毁刚体、静态合批）。这样初始状态是"几层楼板悬在空中"，符合煎饼式坍塌的物理图景。

1. **撒点（Poisson-disk + jitter）**
   在 `spawnboundx × spawnboundz` 的矩形内用 Bridson 算法做泊松盘采样（候选点），再用**最远点抽样**
   挑出 8–11 个空间均匀的种子点，最后做小幅抖动。
   > 注意：Bridson 的返回顺序是空间连续的，"取前 N 个"会得到一簇聚集点，直接导致大量细长碎片。
   > 必须先做最远点抽样，这是踩过的坑。

2. **沃罗诺伊切割**
   每个格子的多边形 = 矩形被「该点与所有其它点的垂直平分线」依次裁掉的交集（凸多边形）。
   按内切半径 ≥ 8 cm、等周比 ≤ 2.5 过滤掉针状/长条格子。

3. **不留缝（碎片严丝合缝）**
   默认**不做曲线收缩**：每个格子直接使用沃罗诺伊原始轮廓，因此**一层就是一块完整的楼板**（日志里 `cover 9.0/9.0 m2`）。
   碎片之间的分离交给物理阶段的**板间斥力**（见第 10 步），而不是几何上的切缝。
   需要老式切缝时仍可用 `-procinset <m>` 打开。

4. **厚度**
   整场只随机取一次（120–180 mm，`-procthicknessmin/max`），所有碎片、所有层共用，模拟"同一批浇筑"。

5. **共享分界线上的 Perlin 噪声**
   轮廓先复制成上下两份，再沿**碎片之间的分界线**注入噪声：噪声的采样位置取在**原始沃罗诺伊边界**上，
   因此裂缝两侧得到**镜像互补**的起伏——像真的裂开，且**两块永远不会互相侵入**（一块凸出多少，邻居就凹进多少）。
   位移沿边法线，振幅按格子尺寸取：`clamp(1.5%·√面积, 5, 25 mm)`（`-procnoisefraction` 可调）。
   边细分默认 0.35 m：点少 → 折线感、不平滑。

6. **上下曲面**
   顶面额外叠加竖向噪声（`-procverticalnoise`，默认 0.15×厚度），底面保持水平以便落地稳定。

7. **放样**
   下轮廓 → 上轮廓生成封闭实体（侧壁 + 上下盖）。盖面用**耳切法**三角化：噪声后的轮廓是非凸的，
   扇形三角化会在非凸处翻折出空洞（这正是早期"模型透视/破面"的根因之一）。

8. **逐面朝外定向 + 平面着色**
   每个三角形独立判断：若其法线指向"体内参考点"（顶点均值）则翻转。板是近凸实体，这个判据准确且不依赖连通性。
   顶点**不焊接**、法线**逐面给定**（不做 `RecalculateNormals` 的邻面平均），保证板的棱角清晰。
   > 两个踩过的坑：① 只对"面表"做定向、之后崩角切割新生成的面没定向 → 大量面朝内、渲染发黑；
   > ② 为了做连通性判断而焊接顶点并让 Unity 平均法线 → 板面出现斑驳的渐变（"颜色混杂"）。

9. **随机崩角**
   对 0–90° 的角按 `(90°−angle)/90°` 取概率，用一次平面切割削掉顶角，切深 = 厚度的一半。
   **小于 50° 的针尖角一律削掉**：两块三角形碎片"顶角相对"互相支撑的姿态非常不自然。

10. **模拟期斥力**
    同层（竖向距离 < 2.5×厚度）且水平距离 < `-procrepulsionrange` 的板之间施加轻微水平斥力
    （`-procrepulsion`，默认 2.5 m/s²），避免碎片被解算器"粘"成一整块。

## 3. 碎片实体与物理

| 项 | 做法 |
|---|---|
| 网格 | 运行时生成 `Mesh`（闭合实体，法线朝外） |
| 碰撞体 | `MeshCollider` + `convex = true`（顶点数 ~30–90，远低于 PhysX 上限） |
| 质量 | `-debrisdensity`（默认 2400 kg/m³）× 网格真实体积（散度定理），本场景单块 27–500 kg |
| 碰撞检测 | `ContinuousDynamic`（项目地面的碰撞体厚度≈0，必须防穿地） |
| 接地 | `-pancakecatchfloor 1` 在 y=0 加一层 60×2×60 m 的隐形物理地板 |
| 材质 | 纯色 URP/Lit（白模）+ 双面（`_Cull = 0`）；颜色 `-procslabcolorr/g/b` |

## 4. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `-procdebris 0/1` | 0 | 启用程序化生成（忽略 prefab 碎片库与随机缩放） |
| `-numlayers <n>` | 3 | 层数 |
| `-spawnboundx/-spawnboundz <m>` | 10 | 每层平面尺寸（复用模拟器原有参数） |
| `-spawnposy <m>` | 15 | 第 0 层的高度 |
| `-proclayerspacing <m>` | 3.0 | 层间距（层 k 底面 = `spawnposy + k × 该值`） |
| `-pancakelayergap <s>` | — | 全部层生成后等待多久再冻结 |
| `-proccellsmin/-proccellsmax <n>` | 8 / 11 | 每层碎片数量范围 |
| `-procthicknessmin/-procthicknessmax <m>` | 0.12 / 0.18 | 板厚范围（整场取一次） |
| `-procinset <m>` | 0 | 0 = 不留缝（默认）；> 0 时按该值给每个格子内缩 |
| `-procnoise 0/1` | 1 | 分界线噪声 |
| `-procedgestep <m>` | 0.35 | 边细分长度（越大点越少、越角化） |
| `-procnoisescale <f>` | 3.0 | 噪声频率 |
| `-procnoisefraction <f>` | 0.015 | 噪声振幅占格子尺寸的比例（× √面积），并夹到 5–25 mm |
| `-procverticalnoise <f>` | 0.15 | 顶面竖向噪声（占厚度比例） |
| `-proccorners 0/1`、`-proccornerchance <f>` | 1 / 1.0 | 崩角开关与概率倍数 |
| `-procrepulsion <a>`、`-procrepulsionrange <m>` | 2.5 / 1.2 | 板间斥力加速度与作用范围 |
| `-procslabcolorr/g/b <0..1>` | 0.78/0.77/0.74 | 白模颜色 |
| `-debrisdensity <kg/m3>` | 0（关） | 体积质量；本场景用 2400 |
| `-pancakevictim*` | — | 假人相关（边界、身高、朝向抖动、沿法线偏移），见 `DebrisSpawner` |

日志会打印每层统计，便于核对是否退化：
```
procedural layer 1: 10 slabs at y=3.0, cover 6.0/9.0 m2, piece area 0.23-1.59 m2, 7 corner cuts
debris world bounds after freeze: center=(-0.48, 0.31, -0.17) size=(4.93, 0.62, 5.93)
```

## 5. 已知限制

1. **初始贴合会互相挤**：不留缝时同层碎片初始彼此紧贴，落地前后靠斥力与接触解算分开，因此会出现几厘米的相对滑移；
   这是有意为之（几何上严丝合缝 + 物理上靠斥力分离）。
2. **上层落地会翘边**：第二层砸在下层不平整的堆上，部分板会楔进缝里竖起来，因此最终形态是"歪斜的板堆"
   而非完美千层饼。可调小 `-proclayerspacing`、减少层数，或加大切缝改善。
3. **边缘呈锯齿轮廓**：粗采样（0.35 m）+ 顶面竖向噪声使侧壁顶缘起伏明显，视觉上是"毛边"，但也略显规律。
4. **裂缝形态仍偏简单**：沃罗诺伊格是凸多边形，边与边之间只有角点，真实混凝土断裂会有分叉裂纹。
   后续可考虑：格子内再递归切分、沿边加入分支裂纹、或改用基于物理的断裂（Voronoi 碎裂 + 应力场）。
5. **斥力是"权宜之计"**：不留缝后它承担了"让裂缝重新可见"的职责，并非真实接触模型；调大会让碎片互相推开。
6. **层间裂缝对齐**：各层独立撒点，未做错缝处理，上下层裂缝有时会近似对齐。

## 6. 后续改进方向

* 裂纹分叉：在格边中点插入二级分叉，使碎片边缘出现"Y 形"裂纹。
* 分层错缝：相邻层的种子点相互偏移半格，避免上下层裂缝对齐（更像真实坍塌）。
* 碎屑：在切缝处额外生成小块碎屑（当前只保留了整格大小的碎片）。
* 质量/阻尼标定：用实测堆积密度反推 `-debrisdensity` 与阻尼，使落地与静止过程更接近真实。
